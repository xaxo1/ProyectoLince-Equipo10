ABRIR
1. Descomprime el zip.
2. Android Studio: File > Open... > elige ESTA carpeta (SouthTour, la que tiene app y settings.gradle.kts).
3. Trust Project y espera la sincronización (la primera vez descarga librerías nuevas: íconos de Material).
4. Run (botón Play).
